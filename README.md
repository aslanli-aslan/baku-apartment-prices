# Baku Apartment Prices Prediction

This project builds a machine learning model that predicts apartment prices in Baku, Azerbaijan

## Scope

Data will be collected from [bina.az](https://www.bina.az). Project only covers apartment type listings in Baku.
Because of the way the data is collected, the project predicts typical listing price for comparable apartments. It doesn't predict the true value of the apartment directly. It predicts according to market status.
